# TaskTimer

برنامج ماك (منيو بار + نافذة كاملة) بيمشي معاك من أول التاسك لحد تسجيلها في شيت التيم.

## التسطيب لأي حد في التيم

افتح Terminal والصق السطر ده:

```
curl -fsSL https://raw.githubusercontent.com/mo-animation/TaskTimer/main/install.sh | bash
```

بينزّل آخر نسخة ويحطها في Applications ويفتحها. مش محتاج Xcode ولا Command Line Tools. بعد كده التحديثات بتيجي لوحدها من جوه البرنامج.

أول مرة افتح Settings:
- **Sheet:** اكتب اسمك زي ما هو في الشيت، ولينك الـ Web App اللي Mo هيبعتهولك.
- **Folders:** اختار تمبليت الـ AE بتاعك.

## البناء من السورس (للتطوير)

1. فك الضغط وحط الفولدر في أي مكان.
2. دبل كليك على **Build TaskTimer.command**.
   - أول مرة لو الماك طلب **Command Line Tools** وافق وسيبه يخلص (حوالي ١٠ دقايق)، وبعدها دبل كليك تاني.
   - لو الماك قال إن الملف من مطور غير معروف: كليك يمين على الملف ← Open ← Open.
3. البرنامج هيتبني ويتنقل لـ Applications ويفتح لوحده.

## ربط شيت التيم (مرة واحدة)

1. افتح شيت التيم ← **Extensions ← Apps Script**.
2. امسح أي كود موجود، والصق محتوى ملف `GoogleSheet/TaskTimer.gs` كله.
3. غيّر `TOKEN: 'CHANGE-ME'` لأي كلمة سر (مثلاً `mo-2026`).
   - لو التاسكات في تاب مش الأولى، اكتب اسمها في `SHEET_NAME`.
4. **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - اضغط Deploy ووافق على الصلاحيات (Advanced ← Go to … ← Allow).
5. انسخ الـ URL اللي آخره `/exec`.
6. في TaskTimer افتح ⚙️ Settings ← Sheet، واكتب:
   - اسمك زي ما بيتكتب في الشيت.
   - الـ URL.
   - الـ Token نفسه.
7. اضغط **Test Connection**. هيظهرلك الأعمدة اللي اتعرفت (task / date / client / member / status / time).
   - لو عمود ما اتعرفش، حط حرفه بإيدك في `COLUMNS` جوه السكربت، مثلاً `time: 'F'`، وبعدها Deploy ← Manage deployments ← Edit ← New version.

> السكربت بيكتب في الأعمدة الستة دي بس، وما بيلمسش أي عمود تاني في الشيت.

## التحديثات

البرنامج بيحدّث نفسه من GitHub:

- أي تعديل بيتعمل على البرنامج بيترفع على الريبو، وGitHub بيبني نسخة جاهزة على ماك عنده.
- كل TaskTimer متسطب بيشيّك كل ربع ساعة. لو فيه نسخة جديدة بيظهر شريط **Version X is ready** وزرار **Update**.
- **Update** بينزّل النسخة الجاهزة ويركّبها ويفتح البرنامج تاني في ثواني.
- تاسكاتك وإعداداتك والتايمر الشغال بيفضلوا زي ما هما.
- أي تعديل ما بيتبنيش على GitHub ما بيوصلش لحد، فمحدش هياخد نسخة بايظة.
- Settings ← General فيها رقم النسخة، و**Check for Updates**، و**What's new**.

## الشغل اليومي

| خطوتك | في TaskTimer |
|---|---|
| تاسك جديد وصلت على الواتساب | **New Task** (⌘N): اسم التاسك، تختار الكلاينت، والمكان. يعمل شجرة الفولدرات وملف الـ AE من التمبليت ويشغّل التايمر. |
| نقل ملفات التاسك | اسحب الملفات اللي حملتها وارميها على كارت التاسك، وكل نوع هيروح فولدره (شوف الجدول تحت). |
| الشغل على الـ AE | زرار 📁 في الكارت ← Open AE Project أو Open Render Folder. |
| بريك أو شغل على تاسك تانية | ▶︎/⏸ في الكارت أو من المنيو بار. تشغيل تاسك بيوقف التانية لوحده. |
| خلصت | **Done**: تختار Complete أو In Process، وتقدر تعدل الوقت أو الكلاينت أو التاريخ، وبعدين **Log to Sheet**. الصف بيتسجل لوحده. |
| فيدباك على تاسك قديمة | شغّل التايمر عليها تاني، وبعدين Done. هيحدّث نفس الصف بالوقت الكلي، أو يضيف صف جديد بالوقت الجديد بس، حسب ما تختار. |

### الملفات بتروح فين لما ترميها على التاسك

| النوع | الفولدر |
|---|---|
| `.psd` `.psb` `.ai` `.eps` (فوتوشوب وإليستريتور) | `02 - PSD` |
| `.aep` `.aepx` | `01 - AE` |
| صوت: `.wav` `.mp3` `.aif` `.m4a` … | `05 - Sound` |
| صور: `.png` `.jpg` `.tif` `.exr` `.svg` `.webp` `.heic` … | `06 - Images` |
| فيديو: `.mov` `.mp4` `.mxf` `.mkv` `.webm` … | `07 - Videos` |
| أي حاجة تانية (`.pdf` `.zip` فونتات …) | `08 - Others` |

لو رميت فولدر كامل وكل اللي جواه صور، هيروح `06 - Images`، ونفس الكلام مع الفيديوهات. لو جواه أنواع مختلفة هيروح `08 - Others`. فولدرات `03 - For AI` و`04 - From AI` بتحط فيهم بإيدك، لأن نوع الملف لوحده مش بيقول هو رايح للـ AI ولا جاي منه.

### حاجات مفيدة

- **من غير نت؟** الصف بيتحفظ ويتبعت لوحده كل دقيقتين، أو تدوس **Retry** فوق.
- **Settings ← Sheet:** شكل الوقت (2:30 أو 2.5 أو دقايق)، والتقريب لأقرب 5 أو 15 دقيقة.
- **Settings ← Folders:** مسار تمبليت الـ AE وأسامي الفولدرات الفرعية.
- **Settings ← General:** فتح البرنامج مع تشغيل الماك، وإخفاء أيقونة الـ Dock، وإيقاف التايمر لما الماك ينام.
- **فولدرات قديمة:** زرار 📁+ (Import) يضيف أي فولدر تاسك قديم للبرنامج.
- **اختصارات:** ⌘⇧P للإيقاف، ⌘⇧D لـ Done.
- **البيانات:** محفوظة في `~/Library/Application Support/TaskTimer/data.json`.
